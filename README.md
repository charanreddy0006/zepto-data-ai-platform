# Zepto Data & AI Platform

An end-to-end AI/ML engineering capstone integrating web data engineering, exploratory analytics, predictive modeling, RAG-based GenAI, FastAPI, and Docker.

## Project Modules

### 1. Data Pipeline

Web scraping, data cleaning, currency conversion, relational database design, SQL querying, and Pandas analysis.

### 2. Analytics Pipeline

Titanic dataset profiling, exploratory data analysis, visualization, classification, regression, model evaluation, hyperparameter tuning, and model persistence.

### 3. Support Assistant

Document ingestion, embeddings, ChromaDB vector retrieval, LangGraph orchestration, structured responses, FastAPI, and Docker.
